# abyss

Keep the light alive.

A bioluminescent deep-sea ecosystem with real game mechanics — flocking behavior, an Angler with a deceptive lure, sync pulse mechanics, and creatures you'll find yourself rooting for.

Built in Phaser 3. All procedural — no image assets, no audio files. Everything you see is math and geometry and timing.
